# もじカズ たんけんたい

小学1年生むけの こくご・さんすう ドリル。ポケモンを あつめながら 1かい 15ふん。

- **漢字はいっさい出てきません**（問題文もUIも ひらがな・カタカナのみ）
- iPad / iPhone の Safari 用。「ホーム画面に追加」で全画面アプリになります
- 通信なしで動きます（データも画像もページに埋め込み済み）
- 進捗は端末の localStorage に保存

## あそびかた

1回の「たんけん」＝ **ポケモン4体 × 各5問正解**（だいたい12〜18分）。

- 野生のポケモンが現れ、正解するたびにHPが減り、5回正解でゲット
- 同じ系統を **3回つかまえると進化した姿**、**6回で最終進化**が出現
- ✨ 色違い（約1/45）と でんせつのポケモン（約1/70）が まれに出現
- まちがえた問題は そのバトルの終盤に もう一度出題（減点はなし）

**第1世代＋第2世代（カントー／ジョウト）の251匹**。野生で出会うのは進化前の111種で、
残りは進化で図鑑に加わります。半分の確率で「進化が近い系統」が優先して出るので、
進化が起きないまま新種ばかり増えることはありません。
1日1回のペースで、30回で約70匹、180回で約220匹が埋まる想定です。

## もんだいの しゅるい

**ことばの もり（こくご）** — てんてん・まる／ちいさい っ・ゃゅょ／のばす おと／かたかな／なかまの ことば／はんたいの ことば／は・を・へ／かぞえかた／しりとり／おとの かず／ことばづくり

**かずの みずうみ（さんすう）** — たしざん／ひきざん／いくつと いくつ／くりあがり・くりさがり／3つの かず／おおきさくらべ／かずの ならび／10の まとまり／とけい／ぶんしょうだい

**まざりの どうくつ** — 両方ミックス

計算問題はテンキー入力、それ以外は選択式。むずかしさは ★ / ★★ / ★★★ の3段階。

## ファイル

| | |
|---|---|
| `index.html` | 公開されるページ（ビルド生成物・直接編集しない） |
| `artifact.html` | Claude Artifact 用のフラグメント（同上） |
| `icon.png` | ホーム画面アイコン（同上） |
| `src/app.html` | **編集するのはここ**。`/*__PK__*/` にデータが差し込まれる |
| `build/fetch-poke.js` | PokeAPI からデータとスプライトを取得 → `build/pokedata.js` |
| `build/pokedata.js` | 取得済みデータ（251匹・約0.5MB・生成物） |
| `build/build.js` | テンプレート＋データ → 公開用ファイル |

## ビルド

```sh
node build/build.js          # src/app.html から index.html を作りなおす
node build/fetch-poke.js     # PokeAPI から取りなおす（通常は不要）
```

`fetch-poke.js` は PokeAPI から 日本語名・タイプ・進化チェーン・通常/色違いスプライトを取得し、
すべて base64 で `pokedata.js` に書き出します。実行時に外部通信をしないのは、
オフラインでも動かすためと、Claude Artifact の CSP が外部fetchを禁じているためです。
