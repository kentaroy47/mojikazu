# もじカズ たんけんたい

小学1年生むけの こくご・さんすう ドリル。ポケモンを あつめながら 1かい 15ふん。

- **漢字はいっさい出てきません**（問題文もUIも ひらがな・カタカナのみ）
- iPad / iPhone の Safari 用。「ホーム画面に追加」で全画面アプリになります
- 通信なしで動きます（データも画像もページに埋め込み済み）
- 進捗は端末の localStorage に保存

## あそびかた

1回の「たんけん」＝ **ポケモン4体 × 各5問正解**（だいたい12〜18分）。

- 野生のポケモンが現れ、正解するたびにHPが減り、5回正解でゲット
- 同じ系統を **3回つかまえると進化した姿**、**6回で最終進化**が出現
- ✨ 色違い（約1/45）が まれに出現
- まちがえた問題は そのバトルの終盤に もう一度出題（減点はなし）

**全9世代・1025匹**（カントー〜パルデア）。野生で出会うのは進化前の453種で、
残りは進化・たまご・でんせつ探検で図鑑に加わります。

### あつめる しくみ

| | |
|---|---|
| **あいぼう** | 図鑑でポケモンを押して選ぶ。問題の横で応援し、正解のたびに なかよし度が上がる（♥5段階） |
| **すみか** | ホームで「くさむら／かわべ／どうくつ／そらとやま」を選ぶと、出会いやすいタイプが変わる |
| **たまご** | 探検を1回終えるごとに ひびが入り、3回で孵化。まだ持っていないポケモンが優先で生まれる |
| **ちずの かけら** | 探検1回につき1枚。5枚そろうと 次の探検の最後に でんせつのポケモンが確定で出る |
| **ずかん** | ポケモンを押すと 詳細カード（進化ライン・タイプ・捕獲数・鳴き声）。地方ごとに絞り込める |

野生は3割強の確率で「もう少しで進化する系統」を優先して出すので、
進化が起きないまま新種ばかり増えることはありません。
1日1回のペースで、30回で約70匹、180回で約390匹、365回で約650匹が埋まる想定です。

## ジムバトル

8つのジムを順番に攻略してバッジを集めます。**集めたポケモンから3体を選んで**戦います。

- **問題に正解 → 自分のポケモンが攻撃**、まちがえる → 相手の攻撃を受ける
- ダメージは**タイプ相性**で変わる（ばつぐん2倍／いまひとつ0.5倍／きかない0倍）
- **連続正解で攻撃が強くなる**（最大+10）。種族値も強さに反映される
- 負けてもペナルティなし。勝つとバッジと ちずのかけら2枚
- チーム選び画面は相性順に並び、各ポケモンに「ばつぐん」「きかない」の目印。迷ったら**おまかせ**

| ジム | タイプ | ジム | タイプ |
|---|---|---|---|
| ムシムシの もり | むし | もりもり おんしつ | くさ |
| ゴツゴツ いわば | いわ | メラメラ かざん | ほのお |
| なみなみ みずうみ | みず | フシギの とう | エスパー |
| ビリビリ はつでんしょ | でんき | そらの きょてん | ドラゴン |

相性を考えたチームなら8〜32問（正答率による）で決着します。適当に選ぶと苦戦し、
たとえば ほのおジムは正答率85%でも勝率37%。**タイプ選びが本当に効きます**。

タイプ相性表は PokeAPI の `damage_relations` から生成しているので本家どおりです
（でんき→じめん 0倍、ノーマル→ゴースト 0倍 など）。
相性0倍だけで固めると永久に決着しないため、60問で打ち切って
「タイプを変えよう」と伝えます。

## ビルド

ホームの「ピカチュウの しま」から、別ページ `island.html` の短い島づくり試作へ移動できます。試作側の「もじカズに もどる」で元のホームへ戻れます。学習記録は別々です。

試作の編集対象は `island-prototype/index.html` と `island-prototype/game.js`。下記ビルドで `island.html` も再生成します。試作のソースがない環境では、保存済みの `island.html` を使います。

```sh
node build/build.js          # src/app.html から index.html を作りなおす
node build/fetch-poke.js     # PokeAPI から取りなおす（通常は不要）
```

`fetch-poke.js` は PokeAPI から 日本語名・タイプ・進化チェーン・通常/色違いスプライトを取得し、
すべて base64 で `pokedata.js` に書き出します。実行時に外部通信をしないのは、
オフラインでも動かすためと、Claude Artifact の CSP が外部fetchを禁じているためです。
